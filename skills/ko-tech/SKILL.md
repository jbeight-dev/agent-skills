# 영문 기술 텍스트 한글 번역

목표: 한국 개발자가 원문 없이 읽어도 막힘없는 번역. 직역보다 의미 전달, 그러나 기술적 정확성은 절대 손상하지 않는다.

## 입력과 출력

- 텍스트를 붙여넣은 경우: 번역문만 응답한다. 서문·요약·해설을 붙이지 않는다.
- 파일 경로를 받은 경우: 원본 옆에 `<이름>.ko.<확장자>`로 저장한다(예: `README.md` → `README.ko.md`). 사용자가 다른 위치나 덮어쓰기를 지정하면 따른다.
- 긴 문서는 섹션 단위로 끊어 번역하되, 용어는 문서 전체에서 일관되게 유지한다.

## 절대 번역하지 않는 것

- 코드 블록, 인라인 코드(`` `...` ``), 명령어, CLI 옵션, 설정 키, 환경 변수
- 식별자(함수·클래스·변수명), 파일 경로, URL, 버전 번호
- 제품·서비스·라이브러리 이름(Kubernetes, React, PostgreSQL 등)
- 코드 블록 안의 주석은 사용자가 요청할 때만 번역한다.

## 형식 보존

- Markdown 구조(제목 레벨, 목록, 표, 링크, 이미지, 각주, HTML 태그)를 그대로 유지한다.
- 링크는 표시 텍스트만 번역하고 URL과 앵커는 유지한다.
- frontmatter는 값 중 사람이 읽는 텍스트(`title`, `description` 등)만 번역한다.

## 용어 원칙

1. **정착된 외래어는 한글 표기**: 서버, 데이터베이스, 스레드, 캐시, 컨테이너, 클러스터, 쿼리, 인덱스
2. **정착된 번역어가 있으면 번역어**: 배포(deploy), 의존성(dependency), 인증(authentication), 권한 부여(authorization), 상속(inheritance), 동시성(concurrency)
3. **번역 시 의미가 흐려지는 용어는 첫 등장 때 병기**: 멱등성(idempotency), 역압(backpressure), 결과적 일관성(eventual consistency). 이후에는 한글만 쓴다.
4. **한국 개발자가 영어 그대로 쓰는 용어는 영어 유지**: commit, merge, pull request, rebase, payload, middleware 같은 용어는 문맥상 더 자연스러운 쪽을 택한다. 어색하면 한글 음차(커밋, 머지)를 쓴다.
5. 사용자가 용어집을 주면 그것이 최우선이다.

## 문체

- 기본은 `~한다` 평서체. 원문이 튜토리얼처럼 독자에게 말을 거는 글이면 `~합니다` 체를 쓴다. 사용자가 지정하면 따른다.
- 한 문서 안에서 문체를 섞지 않는다.
- 원문의 어조(공식/캐주얼)를 유지하되, 영어식 농담·관용구는 의미가 통하게 풀어 쓴다.

## 번역투 피하기

| 피할 표현 | 고칠 방향 |
|---|---|
| 수동태 남용 ("~되어진다", "~에 의해 처리된다") | 능동태로 ("~가 처리한다") |
| "~을 가지다" (have) | "~이 있다", "~을 포함한다" |
| "~에 대해", "~에 있어서" 남발 | 조사로 간결하게 |
| 대명사 직역 ("그것은", "이것들은") | 생략하거나 명사를 다시 쓴다 |
| 불필요한 복수형 "~들" | 문맥상 복수가 분명하면 생략 |
| "~하는 것이 가능하다" (can) | "~할 수 있다" |
| "~할 필요가 있다" (need to) | "~해야 한다" |
| 무생물 주어 ("이 함수는 당신이 ~하게 해준다") | "이 함수로 ~할 수 있다" |
| "당신", "여러분" 직역 (you) | 대부분 생략 |

긴 영어 문장은 한국어 어순에 맞게 둘 이상으로 나눠도 된다. 단, 조건·순서·예외 관계가 바뀌지 않게 한다.

## 정확성 체크

번역을 마치기 전에 확인한다.

- `must` / `should` / `may`(RFC 2119 문맥 포함)의 강도 차이가 유지되는가: 반드시 ~해야 한다 / ~하는 것이 좋다 / ~해도 된다
- 부정·조건·예외(`unless`, `only if`, `except`)가 정확히 옮겨졌는가
- 숫자, 단위, 버전, 기본값이 원문과 같은가
- 코드·식별자가 하나도 바뀌지 않았는가
- 원문이 모호하거나 오류로 보이면 임의로 고치지 말고 번역 뒤에 `> 역주:`로 짧게 남긴다.
