# Editorial Slide Deck — Design System

사용자가 좋아한 "Spark 연결 가이드" 덱의 디자인 시스템. `assets/slide-template.html`이 이 문서의 구현체다. 둘이 어긋나면 이 문서를 기준으로 템플릿을 고친다.

## 스타일 키워드

에디토리얼 미니멀 · 스위스 타이포그래피 · 플랫 · 미색/짙은 남색 · 차콜 그레이 + 단일 레드 포인트(#EA002C / 다크 #FF4D57) · 다크 커버 · 개발자 문서 감성

## 폰트

- 본문/제목: Noto Sans KR (400/500/700/900)
- 코드: JetBrains Mono (400/600)
- Google Fonts에서 로드

## 색상 토큰

포인트 컬러: RGB 234, 0, 44 = `#EA002C` (브랜드 고정색).

```css
:root{ /* Light */
  --bg:#1b1f27; --paper:#fbfaf7; --ink:#1d2330; --muted:#6b7280; --line:#e6e2d8;
  --accent:#ea002c; --accent-soft:#fde6ea; --neutral:#4b5563; --neutral-soft:#ecebe6;
  --green:#15803d; --green-soft:#e6f4ea; --code-bg:#1e2330; --code-ink:#e6e9ef;
}
html[data-theme="dark"]{
  --bg:#0b0e13; --paper:#15191f; --ink:#e5e7eb; --muted:#9ca3af; --line:#303641;
  --accent:#ff4d57; --accent-soft:#33191d; --neutral:#d1d5db; --neutral-soft:#303641;
  --green:#4ade80; --green-soft:#132a1c; --code-bg:#0f1217; --code-ink:#e5e7eb;
}
```

다크 테마에서 `--accent`를 `#FF4D57`로 한 단계 밝히는 이유: `#EA002C`를 어두운 배경 위 작은 글자에 쓰면 대비가 부족함. 면을 채우는 요소(단계 번호 원, 거버넌스 라벨, 진행 바 등)는 다크에서도 원색 `#EA002C` + 흰 글자.

### 원칙

- 순백·순검정 금지(눈부심 방지).
- 강조는 포인트 빨강 하나. 파랑은 쓰지 않는다. 일반 요소(배지·테두리·콜아웃 면)는 회색으로 통일하고, 강조할 요소(추천 카드·흐름 화살표·콜아웃 세로선)에만 빨강.
- 초록은 "사실/완료" 의미의 태그·카드 테두리에만.
- 더 차분한 빨강이 필요하면 다크 `--accent`를 `#D94B55`로.

## 타이포 스케일 (1024×768 기준)

| 요소 | 규격 |
|---|---|
| 커버 h1 | 54px / 900 / letter-spacing -.02em |
| 슬라이드 h2 | 38px / 900 |
| 키커(제목 위 라벨) | 15px / 700 / letter-spacing .12em / 포인트 색. 예) "STEP 1 · 현황 확인" |
| 본문 p | 21px / line-height 1.65, 리드 23px |
| 코드 | 18px mono, line-height 1.6 |
| 푸터 | 13px muted, 좌측 덱 제목 · 우측 2자리 페이지 번호 |
| 슬라이드 패딩 | 64px 72px 72px |

## 컴포넌트

- **거버넌스 메시지 (`.gov`)**: 제목(h2) 바로 아래, `margin: -14px 0 22px`. 2px 테두리 박스, 왼쪽에 "⚠ 거버넌스" 라벨칩(13px 700 흰 글자), 본문 17px. 주의·전제조건·규칙은 하단 콜아웃 대신 여기에 둔다.
- **정보 콜아웃 (`.callout.b`)**: 슬라이드 하단(`margin-top: auto`), 차콜 면(`--callout-bg`) + 포인트 빨강 좌측 5px 바. 일반 팁·결론용.
- **카드 (`.card`)**: 1.5px 라인 테두리, radius 14px. 3열 그리드(`.grid3`) 또는 2열 비교(`.vs`). 추천 카드는 테두리를 포인트(`.card.on`) / 초록(`.card.ok`)으로.
- **태그 (`.tag.o` / `.b` / `.g`)**: 알약형 14px 700, 연한 면 + 진한 글자.
- **단계 행 (`.row` + `.step`)**: 34px 원형 번호 + 21px 굵은 제목.
- **코드 블록 (`.code`)**: 다크 배경, radius 10px. 구문 색 — 키워드 `.k` #ff7a90, 문자열 `.s` #a5d6a7, 함수 `.f` #d1d5db, 주석/프롬프트 `.c` #7c8597.
- **예시 값 (`code.i`)**: namespace, 서비스명 등 사용자가 바꿔야 하는 값. "본인 값으로 바꾸라"는 안내를 함께 단다.
- **형광펜 (`mark`)**: 문장 속 핵심 구절.
- **표**: 헤더 15px muted, 하단 2px ink 선, 행 구분 1px line. 포트·ID 같은 값은 mono 600 (`.mono`).
- **흐름도 (`.flow`)**: 박스(`.node`) + 화살표(`.arrow`, 위 →, 아래 작은 라벨). 핵심 노드는 `.node.on`(포인트 테두리 + 연한 면).
- **커버 슬라이드 (`.cover`)**: 어두운 배경, 우측 상단에 거대한 반투명 ✦ 장식(420px), 키커 + h1 + muted 부제.
- **슬라이드 전환**: opacity + translateX(±24px), .35s ease.

## 내비게이션 / 크롬

- 슬라이드 넘김: ←/→, Space, PageUp/Down, Home/End, 터치 스와이프
- `F` = 전체화면, `D` = 테마 전환
- 하단 중앙 알약형 내비 (‹ 현재/전체 › ◐ ⛶), 상단 4px 진행 바(포인트 색)
- URL 해시(`#3`)로 현재 슬라이드 유지. 테마 선택은 localStorage(try/catch)로 기억
- 코드 블록마다 우측 상단 "복사" 버튼 (`$ ` 프롬프트는 복사에서 제외)
- 기본 테마: 다크. `<html data-theme="dark">`
