# Editorial Slide Deck (4:3 HTML)

사용자가 좋아한 "Spark 연결 가이드" 덱의 디자인을 그대로 따라 기술 가이드·온보딩·사내 교육 슬라이드를 만든다.

## 출력 형식

- 단일 self-contained HTML 파일 (Google Fonts만 외부 로드)
- 1024×768(4:3) 고정 캔버스를 창 크기에 맞춰 scale
- 기본 테마 다크 `<html data-theme="dark">`, `D`로 테마 전환, `F`로 전체화면
- 키보드(←/→, Space, PageUp/Down, Home/End)·터치 스와이프 내비게이션
- URL 해시(`#3`)로 현재 슬라이드 유지
- 코드 블록 복사 버튼 (`$ ` 프롬프트 제외)

## 디자인 규칙

색상·폰트·타이포·컴포넌트는 반드시 `references/design-system.md`를 따른다.

## HTML 구현

`assets/slide-template.html`을 복사해 `<section class="slide">`만 교체한다. CSS·JS는 고치지 않는다. 템플릿의 예시 슬라이드가 각 컴포넌트 사용법이다.

## 덱 구성 원칙

1. 표지 (다크 커버)
2. "먼저 알아둘 점" — 흔한 오해를 비교 카드(`.vs`)로
3. 큰 그림 — 선택지 3가지 카드(`.grid3`)
4. 4~N번: STEP 단위로 한 슬라이드 = 한 행동. 키커에 "STEP n · 요약"
5. 구조를 이해해야 하는 지점엔 흐름도 슬라이드 1장 추가
6. 마지막: 다크 커버로 "지금 바로 할 일" + 복사 가능한 명령어 + 확인할 항목 태그

## 작업 방식

1. 원문 내용을 빠짐없이 옮기되 초보자 눈높이로 쪼갠다.
2. 원문의 빈칸은 합리적으로 채우고 응답에서 한 줄로 알린다.
3. 예시 값(namespace, 서비스명 등)은 `code.i`로 표시하고 "본인 값으로 바꾸라"는 안내를 단다.
4. 주의·전제조건·규칙은 제목 아래 거버넌스 메시지(`.gov`)로, 일반 팁은 하단 콜아웃(`.callout.b`)으로.
5. 완성 후 파일로 전달하고, 구성(슬라이드 목록)과 조작법을 짧게 안내한다.
