# Editorial Slide Deck

## 목적

기술 가이드 및 교육 자료를
4:3 비율의 HTML 슬라이드로 생성한다.

## 출력 형식

- 단일 self-contained HTML 파일
- 1024×768 고정 캔버스
- 화면 크기에 맞춰 자동 확대/축소
- 기본 다크 테마
- 키보드 및 터치 내비게이션 지원
- 코드 블록 복사 기능 제공

## 디자인 규칙

반드시 다음 문서를 참고한다.

- `references/design-system.md`

## HTML 구현

가능하면 다음 템플릿을 기반으로 생성한다.

- `assets/slide-template.html`

## 슬라이드 구성 원칙

1. 표지: 다크 커버
2. 먼저 알아둘 점
3. 전체 구조 및 개념 설명
4. STEP 단위의 상세 가이드
5. 필요시 흐름도 추가
6. 마지막: 지금 바로 할 일

## 작업 방식

1. 사용자 원문 분석
2. 슬라이드 구성 설계
3. 디자인 시스템 적용
4. HTML 생성
5. 슬라이드 동작 검증
6. 완성된 HTML 파일 전달

## 주의사항

- 원문 내용을 누락하지 않는다.
- 초보자 눈높이에 맞게 설명한다.
- 예시 값은 명확하게 구분한다.
- 브랜드 포인트 컬러를 유지한다.
