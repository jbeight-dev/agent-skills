# 기술 문서 → 한국어 HTML

영문 기술 문서를 번역해 브라우저에서 바로 열 수 있는 HTML 파일 하나로 저장한다.

## 입력과 출력

- 입력: `.md`, `.html`/`.htm`, `.txt`. 디렉터리를 받으면 안의 파일을 하나씩 처리하고, 이미 있는 `*_ko.html`은 건너뛴다.
- 출력: 확장자를 떼고 `_ko.html`을 붙여 원본과 같은 디렉터리에 저장한다(`docs/guide.md` → `docs/guide_ko.html`).
- 원본은 수정하지 않는다. 출력 파일이 이미 있으면 덮어쓰기 전에 확인한다.

## 번역

`ko-tech` skill의 규칙(번역하지 않는 것, 형식 보존, 용어, 번역투, 정확성 체크)을 따른다. 추가 규칙:

- 문체는 `~합니다` 체로 통일한다.
- 요약·생략·설명 추가를 하지 않는다. 원문 오류도 고치지 않는다(필요하면 `역주`를 단다).
- 긴 문서는 섹션 단위로 번역하되 용어는 문서 전체에서 같게 쓴다.

## HTML 생성

`assets/doc-template.html`을 복사해 placeholder만 바꾼다. 템플릿의 CSS·JS는 고치지 않는다.

| placeholder | 값 |
|---|---|
| `{{TITLE}}` (2곳) | 번역한 문서 제목(첫 H1, 없으면 파일명) |
| `{{SOURCE_FILE}}` | 원본 파일명 |
| `{{DATE}}` | 작업 날짜 `YYYY-MM-DD` |
| `<!-- {{CONTENT}} -->` | 번역한 본문 HTML |

본문 변환 규칙:

- Markdown은 시맨틱 HTML(`h1`~`h6`, `p`, `ul/ol`, `table`, `blockquote`, `pre><code class="language-xxx"`, `img`, `a`, `hr`)로 바꾼다. 체크박스는 `<input type="checkbox" disabled>`로 둔다.
- 코드는 HTML escape(`<`, `>`, `&`)만 하고 내용은 한 글자도 바꾸지 않는다.
- 원문 내부 링크(`#anchor`)가 동작하도록 해당 제목에 같은 `id`를 직접 넣는다. id가 없는 제목은 템플릿 JS가 중복 없이 채운다.
- 이미지·링크의 상대 경로는 원본 그대로 둔다(출력 파일이 같은 디렉터리라 그대로 동작한다).
- 원본이 HTML이면 `<script>`, `on*` 이벤트 속성, `javascript:` URL을 제거한다.

목차, 테마 전환, 코드 복사, 표 가로 스크롤, 모바일 레이아웃, 인쇄 스타일은 템플릿이 처리한다.

## 검증과 보고

저장한 뒤 확인한다.

- 원문과 번역문의 제목·코드 블록·표 개수가 같은가
- 코드 블록, 숫자, 버전, 설정값이 원문과 같은가
- placeholder가 남아 있지 않은가(`grep '{{' <출력파일>`)

마지막에 원본 경로, 출력 경로, 번역하지 못했거나 확인하지 못한 항목을 짧게 보고한다. 확인하지 못한 항목을 완료라고 하지 않는다.
