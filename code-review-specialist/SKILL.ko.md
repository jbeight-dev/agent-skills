# 코드 리뷰 스킬

이 스킬은 다음 항목에 중점을 둔 종합 코드 리뷰 기능을 제공한다.

1. **보안 분석**
   - 인증/권한 부여 문제
   - 데이터 노출 위험
   - 인젝션 취약점
   - 암호화 취약점
   - 민감한 데이터 로깅

2. **성능 리뷰**
   - 알고리즘 효율성(Big O 분석)
   - 메모리 최적화
   - 데이터베이스 쿼리 최적화
   - 캐싱 적용 기회
   - 동시성 문제

3. **코드 품질**
   - SOLID 원칙
   - 디자인 패턴
   - 명명 규칙
   - 문서화
   - 테스트 커버리지

4. **유지보수성**
   - 코드 가독성
   - 함수 크기(50줄 미만이어야 한다)
   - 순환 복잡도(cyclomatic complexity)
   - 의존성 관리
   - 타입 안전성

## 참조 파일

이 스킬에는 리뷰할 때 읽어야 하는 보조 파일이 있다.

- **`templates/review-checklist.md`** — 보안, 성능, 품질, 테스트를 다루는 구조화된 체크리스트. 이 파일을 읽고, 리뷰 중 빠뜨리는 범주가 없도록 가이드로 활용한다.
- **`templates/finding-template.md`** — 개별 발견 사항을 심각도, 위치, 코드 예시, 영향 분석과 함께 기록하는 표준 템플릿. 이 파일을 읽고, 문제를 보고할 때 이 형식을 따른다.
- **`scripts/analyze-metrics.py`** — 코드 지표(함수 수, 클래스 수, 평균 줄 길이, 복잡도 점수)를 계산하는 Python 스크립트. 리뷰 대상 파일에 실행해 정량 데이터를 수집한다.
- **`scripts/compare-complexity.py`** — 한 파일의 두 버전 사이에서 순환 복잡도와 인지 복잡도(cognitive complexity)를 비교하는 Python 스크립트. 리팩터링 변경을 리뷰할 때 변경 전후 버전을 넣어 실행한다.

## 리뷰 템플릿

리뷰한 코드마다 다음을 제공한다.

### 요약
- 전체 품질 평가(1-5)
- 주요 발견 사항 수
- 우선 개선 권장 영역

### 치명적 문제(있는 경우)
- **문제**: 명확한 설명
- **위치**: 파일과 줄 번호
- **영향**: 왜 중요한가
- **심각도**: Critical/High/Medium
- **수정**: 코드 예시

### 범주별 발견 사항

#### 보안(문제가 발견된 경우)
보안 취약점을 예시와 함께 나열한다

#### 성능(문제가 발견된 경우)
성능 문제를 복잡도 분석과 함께 나열한다

#### 품질(문제가 발견된 경우)
코드 품질 문제를 리팩터링 제안과 함께 나열한다

#### 유지보수성(문제가 발견된 경우)
유지보수성 문제를 개선 방안과 함께 나열한다
