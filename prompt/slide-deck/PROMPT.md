# 프롬프트 예시

`/editorial-slide-deck` 스킬을 사용해서 `@발표자료_텍스트_261021.md` 내용을 4:3 HTML 슬라이드로 만들어줘.

**필수 조건**
1. 원문의 제목, 문장, 수치, 기술 용어를 절대로 변경하지 않는다.
2. 내용을 요약하거나 임의로 추가·삭제하지 않는다.
3. 원문의 페이지 구분과 순서를 그대로 유지한다.
4. 디자인과 레이아웃만 스킬의 디자인 시스템에 맞게 적용한다.
5. 텍스트가 많더라도 내용을 생략하지 않고, 폰트 크기와 배치를 조정한다.
6. 텍스트 가독성을 우선하며, 요소가 겹치거나 슬라이드 밖으로 잘리지 않도록 한다.
7. 완성된 결과는 단일 HTML 파일로 저장한다.

**작업 완료 후**
- 원본 Markdown과 HTML의 텍스트 누락 여부를 검증한다.
- 슬라이드별 텍스트가 원본과 일치하는지 확인한다.
- 변경되거나 누락된 내용이 있다면 보고한다.
